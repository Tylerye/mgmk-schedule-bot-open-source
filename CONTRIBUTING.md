# Как помочь проекту

Для разработки нужен Node.js >=22.13.0. Установите зависимости через `npm ci`.
Тесты используют поддельные Telegram API и временные локальные базы:

```sh
npm test
node scripts/check-repository-privacy.js --directory
npx wrangler deploy --config wrangler.example.jsonc --dry-run
npx wrangler deploy --config wrangler.personal.example.jsonc --dry-run
```

Нагрузочные сценарии по умолчанию выключены. Не включайте их против рабочего
бота. Для обычных тестов токен Telegram и Cloudflare-аккаунт не нужны.

В PR опишите проблему, изменение поведения и выполненные проверки.
Сохраняйте подгруппы, примечания, повторяющиеся номера уроков и все группы
каталога, в том числе с ошибкой разбора. Не повторяйте неоднозначные отправки
Telegram и не объединяйте минутные lanes в один тяжёлый вызов.

Вносите только код, на который у вас есть права, под лицензией MIT проекта.
Не добавляйте реальные PDF с персональными данными и production credentials.
